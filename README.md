# Disputa

App local (KMP + SwiftUI, iOS 18+) para campeonatos de EA FC entre amigos.

Abra `iosApp/Disputa.xcodeproj`. O target dispara `./gradlew :shared:embedAndSignAppleFrameworkForXcode`.

```
export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
./gradlew :shared:jvmTest
```
